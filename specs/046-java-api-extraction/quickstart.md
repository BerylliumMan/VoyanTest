# Quickstart: Java 接口自动提取与变更触发

## 1. 前置

- 平台已启动，项目存在
- 代码仓库可只读访问（HTTPS token 或 SSH 私钥；公共仓库可留空凭据）
- 项目已有接口用例（`case_kind='api'`，关联到接口定义）——变更触发只会执行有关联用例的接口

## 2. 绑定仓库

接口定义页 →「代码仓库」：

| 字段 | 说明 |
|---|---|
| 仓库地址 | HTTPS 或 SSH；URL 内自带的 `user:token` 会自动拆出并加密 |
| 分支 | 默认 `main`；空 = 远端默认分支 |
| 凭据 | HTTPS：token 或 `user:token`；SSH：私钥内容。留空表示不修改 |
| 同步方式 | `定时`（默认，按间隔巡检）或 `手动` |
| 同步间隔 | 5–1440 分钟 |
| 提取方式 | `自动`（OpenAPI 优先）/ `openapi` / `spring_source` |
| 源码目录 | 多模块仓库可指定，如 `user-service/src/main/java` |
| 确认窗口 | 5–1440 分钟；留空继承全局 60 |
| 全量校准 | 每 N 次增量后做一次全量（默认 10） |

保存后点「连通性测试」验证地址与凭据（只列远端引用，不克隆）。

## 3. 同步与查看

- 「立即同步」：只同步接口定义
- 「同步并检查变更」：同步后立即计算影响并生成计划（不必等巡检）
- 同步记录支持按状态筛选；运行中可点「取消同步」（文件粒度中断）
- 接口列表显示来源条：提取器 / 文件:行 / 可信度；低可信会标注原因
- 接口详情可打开「人工修正（同步不覆盖）」

## 4. 变更触发

1. 定时巡检（默认每 5 分钟）发现新提交
2. 计算「变更文件 → 接口 → 用例」
3. 生成待确认计划（窗口默认 60 分钟，可按项目覆盖）
4. 三种结局：
   - 人工「确认执行」→ 立即创建批次并执行
   - 人工「取消」→ 不执行，记录操作人
   - 超时 → 自动执行；超过宽限（默认 10 分钟）才被发现则标记 `expired_skipped`，不补跑
5. 失败自动重试 2 次（5 / 15 分钟退避）
6. 执行结果：计划行可点批次号跳转报告

## 5. 配置项（环境变量）

| 变量 | 默认 | 说明 |
|---|---|---|
| `api_extract_enabled` | true | 总开关 |
| `api_extract_sync_interval_minutes` | 30 | 默认巡检间隔 |
| `api_sync_confirm_window_minutes` | 60 | 全局确认窗口 |
| `api_sync_misfire_grace_minutes` | 10 | 错过窗口宽限 |
| `api_change_plan_max_pending` | 5 | 单项目待确认上限（超出并入最新） |
| `api_repo_clone_timeout_seconds` | 300 | 拉取超时 |
| `api_extract_max_scan_files` | 20000 | 单次扫描文件上限 |
| `api_extract_full_sync_every` | 10 | 默认全量校准间隔 |

## 6. 常见问题

- **克隆失败**：检查地址/分支/凭据；同步记录会给出原始错误
- **没有 OpenAPI 但有接口**：确认 `@RestController` 与 `@RequestMapping` 存在
- **路径是 `/{id}` 且低可信**：类级路径用了无法解析的常量（如配置中心），需人工修正
- **变更没有生成计划**：受影响的接口没有关联用例；或提交未命中任何 `source_file`
- **接口消失但仍在列表**：状态为 `offline`（保留用例引用），不是删除
