# Quickstart: 断言增强与自动补用例鉴权

## 断言增强

1. 从 OpenAPI 导入带响应 schema 的接口（如 `GET /orders/{id}`）。
2. 生成用例，检查断言：
   - 状态码 2xx（>=200）
   - 状态码 2xx（<300）
   - 响应符合 JSON Schema
3. 构造一个返回 200 但缺少必填字段的响应，执行应失败并指出字段路径。

## 自动补用例鉴权

1. 项目内先有登录接口定义（POST，请求体含 `password`，路径含 `login/token/auth`）。
2. 提交一个需要鉴权的新接口（`request_schema.security` 非空）。
3. 触发「同步并检查变更」。
4. 自动补出的用例应为两步：登录 → 调用，调用请求头带 `Bearer {{token}}`。
5. 没有登录定义时，用例为单步，说明中提示需提供 token。

## 已知限制

- 登录凭证需在响应体中；Cookie 型登录暂不支持。
- 源码提取的接口一般没有响应 schema，结构断言不会生效（仍校验 2xx）。
